A database is an organized collection of electronic data managed by a software program known as a Database Management System (DBMS).

Overview;
• Definition: A structured digital system that stores, updates, retrieves, and secures data efficiently.
• DBMS: The software interface between the user/application and the physical storage (e.g., MySQL, PostgreSQL, Oracle, MongoDB).
• Core Goal: To eliminate data duplication, ensure accuracy, and provide fast, multi-user access.

Key Topics & Concepts;
Database Models
• Relational Databases (RDBMS): Stores data in tabular rows and columns with strict schemas and uses Structured Query Language (SQL). Examples: MySQL, PostgreSQL.
• NoSQL Databases: Handles unstructured or semi-structured data using document, key-value, graph, or wide-column formats. Examples: MongoDB, Redis, Cassandra.
• Other Models: Hierarchical (tree-like) and network (graph-like) databases.
Core Principles & Architecture
• Primary & Foreign Keys: Primary keys uniquely identify a table row; foreign keys link separate tables together.
• ACID Properties: Atomicity, Consistency, Isolation, and Durability—guaranteeing reliable transaction processing.
• Normalization: Splitting data into related tables to reduce redundancy and prevent errors.
• CRUD Operations: Create, Read, Update, and Delete—the basic functions of data management.
• Indexing: Special data structures that speed up query retrieval times.

Real-World Applications;
• Web & E-Commerce: Managing user authentication, shopping carts, product catalogs, and dynamic content (e.g., MySQL, MongoDB).
• Banking & Finance: Processing secure ledger entries, ATM transactions, and account balances with strict ACID compliance.
• Social Media & Entertainment: Handling real-time feeds, messaging, media files, and massive concurrent user traffic (e.g., Cassandra, Redis).
• Mobile & Offline Apps: Storing local app preferences and syncing data when reconnected (e.g., SQLite, Firebase).
• Education & Enterprise (ERP/CRM): Tracking student records, grades, human resources, and inventory systems.
