                DATA, CLOUD AND IoT INFRASTRUCTURE

This folder contains independent technical study of data systems,
cloud technologies, IoT, distributed systems, and infrastructure.
Data, cloud, and Internet of Things (IoT) infrastructures form a connected ecosystem where physical sensors generate data, edge and cloud networks process it, and centralized systems deliver real-time operational insights.
    
    Overview of the Infrastructure
* Perception/Edge Layer: Physical devices, sensors, and actuators capture raw environmental or mechanical data (e.g., temperature, motion, video) locally.
* Connectivity Layer: Wireless and wired protocols (Wi-Fi, 5G, cellular, MQTT, HTTP) safely beam data across the network.
* Cloud Infrastructure Layer: Scalable remote resources handle data ingestion, long-term storage, and heavy analytics using GeeksforGeeks Cloud Computing Guide models.
    
    Key Topics
* Cloud Service Models:
	• IaaS (Infrastructure as a Service): Offers raw virtual servers and networking (e.g., AWS EC2).
	• PaaS (Platform as a Service): Provides deployment sandboxes and developer tools like IoT Infrastructure Guide hubs.
	• SaaS (Software as a Service): Delivers ready-to-use finished applications.
* Edge vs. Cloud Processing: Time-sensitive workloads run locally at the edge to reduce latency, while scalable analytics happen in the centralized cloud.
* Data Pipelines & Analytics: Raw streams transition into structured formats via descriptive, predictive, and prescriptive analytics models.
* Security & Governance: Relies on device authentication, end-to-end encryption, and IBM Data Cloud Insights compliance frameworks.
    
    Real-World Applications
* Smart Cities: Real-time monitoring of traffic flows, smart street lighting, and automated waste management.
* Industrial IoT (IIoT): Predictive maintenance on factory machinery to catch hardware failures before they happen.
* Healthcare (IoMT): Remote patient monitoring via wearable medical devices tracking vital signs continuously.
* Supply Chain & Logistics: End-to-end tracking of cargo conditions, temperature-sensitive goods, and warehouse inventories.
