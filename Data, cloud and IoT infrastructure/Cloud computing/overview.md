Cloud computing is the delivery of shared computing resources—including storage, processing power, databases, networking, and software—on demand over the internet, using a pay-per-use model rather than owning physical hardware.

Overview & Core Characteristics
Cloud computing functions similarly to public utilities like electricity: you consume what you need and pay only for what you use.
• On-Demand Self-Service: Provision resources instantly without human intervention from the provider.
• Broad Network Access: Access applications and data from any internet-connected device.
• Resource Pooling & Multi-Tenancy: Shared physical infrastructure serves multiple customers simultaneously while keeping data isolated.
• Rapid Elasticity & Scalability: Automatically scale resources up during traffic spikes and shrink them when demand drops.
• Measured Service: Usage is metered and billed strictly based on consumption.

Key Topics & Models
 Service Models (The Stack);
• Infrastructure as a Service (IaaS): Rent basic computing infrastructure (servers, storage, and networking). You manage the OS and apps (e.g., DigitalOcean).
• Platform as a Service (PaaS): The provider supplies hardware and a software development environment, cutting down maintenance overhead (e.g., Google Cloud Platform).
• Software as a Service (SaaS): Ready-to-use software applications delivered completely online via a web browser or subscription (e.g., Salesforce, Google Drive, Dropbox).
 Deployment Models;
• Public Cloud: Owned and operated by a third-party provider (e.g., AWS, Microsoft Azure), offering shared resources over the public internet.
• Private Cloud: Dedicated strictly to a single organization, run on-premises or hosted privately for maximum security and control.
• Hybrid Cloud: Combines public and private clouds, allowing data and apps to share space and move flexibly between them.
• Multi-Cloud: Uses two or more cloud services from different providers to avoid vendor lock-in or optimize specific workloads.

Common Applications;
• Data Backup & Disaster Recovery: Storing redundant copies of organizational data off-site for fast recovery.
• Big Data Analytics & AI: Processing massive datasets quickly using scalable cloud compute instances and machine learning pipelines.
• Web & Mobile Applications: Hosting customer-facing websites, SaaS apps, and multiplayer video games that scale globally.
• Software Development & Testing (DevTest): Spinning up virtual environments to write, test, and deploy code rapidly.
• Remote Work & Collaboration: Enabling shared tools like cloud documents, virtual desktops, and real-time communication platforms.
• Healthcare & Energy: Managing electronic health records (EHR), medical imaging, and smart-grid energy monitoring
