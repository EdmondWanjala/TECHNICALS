        MEASUREMENT, UNITS, DIMENSIONS AND APPROXIMATION
  PHYSICAL QUANTITIES;
A physical quantity is a measurable property expressed using a numerical value and a unit.
Examples:
Length, mass, time, temperature, electric current and force.

  SI BASE UNITS;
Length = metre (m)
Mass = kilogram (kg)
Time = second (s)
Electric current = ampere (A)
Temperature = kelvin (K)
Amount of substance = mole (mol)
Luminous intensity = candela (cd).

  SI DERIVED UNITS;
Velocity = m/s
Acceleration = m/s²
Force = newton (N) = kg·m/s²
Work/Energy = joule (J) = N·m
Power = watt (W) = J/s
Pressure = pascal (Pa) = N/m²
Charge = coulomb (C) = A·s
Voltage = volt (V) = J/C
Resistance = ohm (Ω) = V/A
Frequency = hertz (Hz) = s⁻¹.

UNIT CONVERSIONS;
Conversion involves changing a quantity from one unit to another without changing its actual magnitude.
Examples:
1 km = 1000 m
1 m = 100 cm
1 hour = 3600 s
1 kg = 1000 g
1 litre = 10⁻³ m³.
Use conversion factors:
    New value = Original value × Conversion factor.
Always arrange the conversion factor so unwanted units cancel.

  DIMENSIONAL ANALYSIS;
Dimensional analysis expresses physical quantities in terms of fundamental dimensions.
 Common symbols:
Length = [L]
Mass = [M]
Time = [T]
Electric current = [I]
Temperature = [Θ].
 Examples:
Velocity = [LT⁻¹]
Acceleration = [LT⁻²]
Force = [MLT⁻²]
Work = [ML²T⁻²]
Power = [ML²T⁻³]
Pressure = [ML⁻¹T⁻²].
Principle of dimensional homogeneity:
All terms being added or equated in a physically meaningful equation must have compatible dimensions.
 Applications:
• Checking the correctness of equations.
• Deriving relationships between physical quantities.
• Converting units.
• Identifying dimensional inconsistencies.

  SIGNIFICANT FIGURES;
Significant figures indicate the precision of a measured or calculated quantity.
 Rules:
• Non-zero digits are significant.
• Zeros between non-zero digits are significant.
• Leading zeros are not significant.
• Trailing zeros after a decimal point are significant.
• Exact counted quantities have unlimited significant figures.
 For multiplication and division:
The answer should generally have the same number of significant figures as the least precise input.
 For addition and subtraction:
The answer should generally have the same number of decimal places as the least precise input.

ROUNDING AND APPROXIMATION;
Rounding simplifies numerical values while maintaining an acceptable level of accuracy.
Example:
    3.14159 to 3 decimal places = 3.142.
Absolute error:
    |Approximate value - True value|
Relative error:
    Absolute error/True value.
Percentage error:
    (Relative error) × 100%.

SCIENTIFIC MEASUREMENT ERRORS;
 Systematic error:
Consistent error caused by instrument calibration or measurement method.
 Random error:
Unpredictable variations in measurements.
 Accuracy:
Closeness of a measurement to the true value.
cPrecision:
Closeness of repeated measurements to one another.

ENGINEERING TIP:
Never perform calculations using incompatible units. Convert quantities into a consistent unit system before substitution, and retain units throughout the calculation.
