            FUNCTIONS, POLYNOMIALS AND COMPLEX NUMBERS
FUNCTIONS:
A function describes a relationship in which every input has exactly one output.
Notation:
    y = f(x
• Domain: Set of all permissible input values.
• Range: Set of all possible output values.
• Independent variable: Input variable, usually x.
• Dependent variable: Output variable, usually y.
  Common functions:
Linear: f(x) = mx + c
Quadratic: f(x) = ax² + bx + c
Polynomial: f(x) = aₙxⁿ + ... + a₁x + a₀
Exponential: f(x) = aˣ
Logarithmic: f(x) = logₐx
Rational: f(x) = P(x)/Q(x)
  OPERATIONS ON FUNCTIONS;
Addition:
    (f + g)(x) = f(x) + g(x)
Subtraction:
    (f - g)(x) = f(x) - g(x)
Multiplication:
    (fg)(x) = f(x)g(x)
Division:
    (f/g)(x) = f(x)/g(x), where g(x) ≠ 0.
Composition:
    (f ∘ g)(x) = f(g(x))
Inverse function:
If y = f(x), interchange x and y and solve for y to obtain f⁻¹(x), provided the function is invertible on the specified domain.
Important:
    f⁻¹(x) is not the same as 1/f(x).

POLYNOMIALS AND ROOTS:
A polynomial is an algebraic expression of the form:
    P(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + ... + a₁x + a₀
  Important concepts:
• Root/zero: A value of x for which P(x) = 0.
• Factor theorem: If P(a) = 0, then (x - a) is a factor.
• Remainder theorem: The remainder when P(x) is divided by (x - a) is P(a).
• Multiplicity: Number of times a root occurs.
For a polynomial of degree n, there are n complex roots counting multiplicity.
  PARTIAL FRACTIONS;
Partial fraction decomposition expresses a complicated rational function as a sum of simpler fractions.
Example:
    1/[(x+1)(x+2)] = 1/(x+1) - 1/(x+2)
Common forms include:
A/(x-a)
A/(x-a) + B/(x-a)²
(Ax+B)/(x²+px+q)
 Applications:
Integration, Laplace transforms, circuit analysis and differential equations.

COMPLEX NUMBERS:
A complex number is expressed as:
    z = a + jb
Where:
a = real part, Re(z)
b = imaginary part, Im(z)
j = √(-1), commonly used in electrical engineering.
Note: In pure mathematics, i is commonly used instead of j.
 Properties:
j² = -1
j³ = -j
j⁴ = 1
Complex conjugate:
    z* = a - jb
Magnitude:
    |z| = √(a² + b²)
Argument:
    θ = tan⁻¹(b/a), with the correct quadrant considered.
Division:
    z₁/z₂ = z₁z₂*/|z₂|²
  POLAR AND EXPONENTIAL FORMS;
Polar form:
    z = r(cos θ + j sin θ)
Exponential form:
    z = re^(jθ)
Where:
r = √(a² + b²)
θ = arg(z)
Euler's formula:
    e^(jθ) = cos θ + j sin θ
Multiplication:
    r₁∠θ₁ × r₂∠θ₂ = r₁r₂∠(θ₁ + θ₂)
Division:
    (r₁∠θ₁)/(r₂∠θ₂) = (r₁/r₂)∠(θ₁ - θ₂)
  Applications:
AC circuit analysis, impedance, signal processing, control systems, Fourier analysis and electrical power engineering.

ENGINEERING TIP:
Become comfortable converting complex numbers between rectangular (a + jb), polar (r∠θ) and exponential forms. Each form is useful for different calculations.
