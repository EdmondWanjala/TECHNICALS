                    AI, ML and Edge AI

This folder contains independent study of artificial intelligence,
machine learning, and edge AI.
Artificial Intelligence (AI), Machine Learning (ML), and Edge AI combine algorithms, data patterns, and local hardware processing to make fast, automated decisions at the data source.
    
    Overview of AI/ML and Edge AI
* Artificial Intelligence (AI): The broad science of mimicking human intelligence to perform complex tasks.
* Machine Learning (ML): A subset of AI where systems use data to learn patterns rather than following rigid rule-based code.
* Deep Learning (DL): An advanced branch of ML utilizing multi-layered neural networks to handle unstructured data like text, audio, and images.
* Edge AI: The practice of running optimized AI and ML models directly on local hardware devices (such as IoT sensors, cameras, and smartphones) instead of a remote cloud server.
    
    Key Topics
* Training vs. Inference: Models are typically trained on massive datasets using powerful cloud or data center infrastructure, while inference (making real-time predictions) happens on local edge hardware.
* Model Optimization Techniques: Edge AI relies on techniques like quantization (reducing numerical precision), pruning (removing redundant neural network connections), and knowledge distillation to shrink models for low-power devices.
* Core Operational Benefits: Edge architecture drastically minimizes network latency, reduces bandwidth costs, improves privacy by keeping data local, and enables reliable offline functionality.
* Learning Paradigms: Encompasses supervised learning (labeled data), unsupervised learning (hidden structures), reinforcement learning (action rewards), and federated learning (collaborative decentralized training).
    
    Real-World Applications
* Autonomous Vehicles: Self-driving cars use Edge AI perception systems to process local camera and lidar data within milliseconds for safety-critical navigation.
* Smart Healthcare: Wearable medical monitors analyze vital signs locally to track anomalies, heart rates, or blood pressure changes instantly.
* Industrial Automation: Smart manufacturing plants utilize edge sensors for machine condition monitoring, predictive maintenance, and real-time quality control.
* Smart Surveillance: Security systems execute local object detection and motion classification to trigger immediate alerts without streaming heavy video feeds to the cloud.
