                INFORMATION THEORY
Information Theory is the mathematical study of information, uncertainty and communication. 
It provides methods for measuring information, encoding data efficiently and transmitting information reliably through communication channels.
It was developed primarily by Claude Shannon, whose work established the mathematical foundation of modern digital communication.
  Main Objectives;
- Measure the amount of information contained in messages.
- Quantify uncertainty in information sources.
- Develop efficient data encoding methods.
- Minimize data storage and transmission requirements.
- Detect and correct errors during communication.
- Determine the maximum reliable information transmission rate.
- Improve communication reliability in noisy environments.
  Applications;
- Digital communication systems.
- Mobile networks (4G, 5G and beyond).
- Computer networking and the internet.
- Data compression and storage.
- Error detection and correction.
- Cryptography and information security.
- Satellite communication.
- Optical fibre communication.
- Artificial intelligence and machine learning.
- Wireless sensor networks.
- IoT and embedded systems.

 FUNDAMENTAL CONCEPTS
  Information;
Information is knowledge conveyed by a message, signal or observation.
In information theory, information is associated with the reduction of uncertainty.
An unexpected event generally provides more information than an event that is already highly predictable.
Example:
- A coin landing heads or tails has two equally likely outcomes.
- A message reporting a highly predictable outcome provides relatively little new information.
- A rare, unexpected outcome provides more information.
  Information Source;
An information source generates messages or symbols to be communicated.
Examples:
- Human speech.
- Text messages.
- Images.
- Video.
- Sensor measurements.
- Computer-generated data.
  Symbols and Alphabets;
A symbol is an individual element generated by an information source.
An alphabet is the set of possible symbols.
Example:
Binary alphabet:
{0, 1}
A binary source generates sequences consisting of zeros and ones.
4-level alphabet:
{A, B, C, D}
  Message;
A message is a sequence of symbols representing information.
Example:
10110101
  Entropy;
Entropy measures the average uncertainty or average information content of a random variable.
It is one of the most important concepts in information theory.
  Redundancy;
Redundancy refers to additional information beyond what is strictly necessary to represent the source information.
It can be used to:
- Detect transmission errors.
- Correct transmission errors.
- Improve communication reliability.
However, redundancy increases the number of bits required for transmission.

 MEASUREMENT OF INFORMATION
  Self-Information;
The self-information of an event measures the information gained when that event occurs.
Formula:
    I(x) = log₂(1/P(x))
Or:
    I(x) = -log₂P(x)
Where:
I(x) = information content in bits.
P(x) = probability of the event.
Important properties:
- More probable events carry less information.
- Less probable events carry more information.
- An event with probability 1 carries zero information.
- An event with probability 0 has theoretically infinite information content, although such an event cannot occur under the assumed model.
Example:
If an event has probability:
    P(x) = 1/2
Then:
    I(x) = -log₂(1/2)
    I(x) = 1 bit.
If:
    P(x) = 1/8
Then:
    I(x) = -log₂(1/8)
    I(x) = 3 bits.
  Unit of Information;
The bit is the standard unit of information.
One bit represents the information associated with choosing between two equally likely alternatives.
Other units:
1 byte = 8 bits
1 kilobit = 1000 bits (SI convention)
1 megabit = 1,000,000 bits
1 gigabit = 1,000,000,000 bits
Note: Computer memory and some software use binary multiples such as KiB, MiB and GiB.
1 KiB = 1024 bytes.

 ENTROPY OF INFORMATION SOURCES
  Shannon Entropy;
Shannon entropy is the expected self-information of a random variable.
For a discrete random variable X:
    H(X) = -Σ P(xᵢ)log₂P(xᵢ)
Where:
H(X) = entropy in bits per symbol.
P(xᵢ) = probability of symbol xᵢ.
  Binary Entropy;
For a binary source with probabilities p and (1-p):
    H(X) = -p log₂p - (1-p)log₂(1-p)
  Properties of Entropy;
1. Entropy is non-negative:
    H(X) ≥ 0
2. Entropy is maximum when all possible outcomes are equally likely.
For a source with M equally likely symbols:
    H(X) = log₂M
3. Entropy is zero when an outcome is completely certain.
4. Entropy measures average uncertainty, not the information content of every individual event.
Example: Binary Source
Suppose a source produces:
P(0) = 0.5
P(1) = 0.5
Then:
    H(X) = -0.5log₂(0.5) - 0.5log₂(0.5)
    H(X) = 0.5 + 0.5
    H(X) = 1 bit/symbol.
This is the maximum entropy of a binary source.
Example: Unequal Probabilities
Suppose:
P(0) = 0.75
P(1) = 0.25
Then:
    H(X) = -0.75log₂(0.75) - 0.25log₂(0.25)
    H(X) ≈ 0.811 bits/symbol.
The source has less uncertainty than the equally probable binary source.

 JOINT ENTROPY AND CONDITIONAL ENTROPY
  Joint Entropy;
Joint entropy measures the uncertainty associated with two random variables considered together.
    H(X,Y) = -ΣΣ P(x,y)log₂P(x,y)
Applications:
- Analysing dependent sources.
- Communication systems.
- Statistical information analysis.
  Conditional Entropy;
Conditional entropy measures the remaining uncertainty in one random variable when another variable is known.
    H(Y|X) = -ΣΣ P(x,y)log₂P(y|x)
Where:
    H(Y|X) = uncertainty remaining about Y after observing X.
  Entropy Chain Rule;
H(X,Y) = H(X) + H(Y|X)
Also:
H(X,Y) = H(Y) + H(X|Y)
  Independent Random Variables;
If X and Y are independent:
H(X,Y) = H(X) + H(Y)
And:
H(Y|X) = H(Y)
  Mutual Information;
Mutual information measures how much information one random variable provides about another.
    I(X;Y) = H(X) - H(X|Y)
Equivalently:
    I(X;Y) = H(Y) - H(Y|X)
It can also be written as:
    I(X;Y) = H(X) + H(Y) - H(X,Y)
Applications:
- Communication-channel analysis.
- Feature selection.
- Data compression.
- Machine learning.
- Information transfer measurement.

 INFORMATION SOURCES AND SOURCE MODELLING
  Discrete Information Source;
A source that produces symbols from a finite or countable alphabet.
Examples:
- Binary data.
- Text characters.
- Digital sensor measurements.
  Continuous Information Source;
A source whose values are continuous over a range.
Examples:
- Speech amplitude.
- Temperature.
- Analog voltage.
- Pressure measurements.
Continuous sources are often represented using probability density functions and differential entropy.
  Memoryless Source;
A source in which the current symbol is statistically independent of previous symbols.
Its output probabilities do not depend on previous symbols.
  Source with Memory;
A source whose symbol probabilities depend on previous symbols or states.
Examples:
- Natural language.
- Speech.
- Video sequences.
- Time-series sensor data.
  Markov Source;
A source in which the probability of the next state depends on the current state, rather than the entire past, under the first-order Markov assumption.
    P(Xₙ₊₁|Xₙ,...,X₀) = P(Xₙ₊₁|Xₙ)
Applications:
- Speech modelling.
- Data compression.
- Pattern recognition.
- Communication systems.

 SOURCE CODING
Source coding is the process of representing information using an efficient code to reduce the number of bits required for storage or transmission.
Its main objective is to remove unnecessary representation redundancy.
  Types of Source Coding;
 Lossless Coding
Compresses data without losing information.
The original data can be reconstructed exactly.
Examples:
- Huffman coding.
- Arithmetic coding.
- Run-Length Encoding (RLE).
- Lempel-Ziv coding.
Applications:
- Text compression.
- Software files.
- Database compression.
- General-purpose data storage.
 Lossy Coding
Reduces data size by discarding information that is considered less important.
The reconstructed data is an approximation of the original.
Examples:
- JPEG.
- MP3.
- AAC.
- Video compression formats.
Applications:
- Audio streaming.
- Digital photography.
- Video transmission.
 Fixed-Length Coding
Every symbol is represented using the same number of bits.
For M symbols:
    n = ceil(log₂M)
Where n is the minimum fixed codeword length.
Example:
For 4 symbols:
    00, 01, 10, 11
Each symbol uses 2 bits.
 Variable-Length Coding
Different symbols are assigned different codeword lengths.
Common symbols generally receive shorter codes, while less common symbols receive longer codes.
This can reduce average code length.
 Prefix Codes
A prefix code is a code in which no codeword is the prefix of another codeword.
This allows unambiguous decoding without requiring separators between codewords.

 HUFFMAN CODING
Huffman coding is a lossless source-coding technique that assigns variable-length binary codewords to symbols according to their probabilities.
More frequent symbols receive shorter codewords.
  Huffman Coding Procedure;
1. List all symbols and their probabilities.
2. Arrange them from lowest to highest probability.
3. Combine the two least probable symbols into one node.
4. Repeat until one combined node remains.
5. Assign binary digits to the branches.
6. Read the codeword for each original symbol.
7. Calculate the average code length.
  Average Code Length;
L = ΣP(xᵢ)lᵢ
Where:
P(xᵢ) = symbol probability.
lᵢ = codeword length.
  Coding Efficiency;
η = (H(X)/L) × 100%
Where:
H(X) = source entropy.
L = average code length.
  Important Properties;
- Lossless compression.
- Variable-length codewords.
- Prefix-free structure.
- Efficient for many non-uniform sources.
Applications:
- File compression.
- Image compression.
- Data transmission.
- Multimedia encoding.

 SHANNON-FANO CODING
Shannon-Fano coding is a variable-length source-coding technique that assigns shorter codewords to more probable symbols.
  Procedure;
1. Arrange symbols in descending order of probability.
2. Divide the symbols into two groups with approximately equal total probabilities.
3. Assign 0 to one group and 1 to the other.
4. Repeat the division recursively.
5. Continue until every symbol has a unique codeword.
  Characteristics;
- Lossless coding.
- Variable-length representation.
- Prefix-free construction.
- Generally less efficient than Huffman coding.
Applications:
- Understanding source coding.
- Basic data compression studies.

 SOURCE CODING THEOREM
  Shannon Source Coding Theorem;
For a discrete memoryless source with entropy H(X), the average length of a uniquely decodable binary code cannot be less than the source entropy.
    L ≥ H(X)
For suitable lossless block codes, the average number of bits per source symbol can approach H(X) as block length increases.
  Significance;
The theorem establishes the theoretical lower limit of lossless data compression.
It explains why:
- Highly predictable data can be compressed more efficiently.
- Random data with maximum entropy is difficult to compress without loss.
- Efficient coding aims to minimize average codeword length.

 INFORMATION TRANSMISSION AND COMMUNICATION CHANNELS
  Communication System;
A communication system transfers information from a source to a destination through a transmission medium.
  Basic model:
Information Source
       ↓
Source Encoder
       ↓
Channel Encoder
       ↓
Modulator / Transmitter
       ↓
Communication Channel
       ↓
Receiver / Demodulator
       ↓
Channel Decoder
       ↓
Source Decoder
       ↓
Destination
  Communication Channel;
A communication channel is the medium through which information is transmitted.
Examples:
- Copper cables.
- Optical fibre.
- Radio waves.
- Satellite links.
- Wireless networks.
 Channel Noise
Noise is unwanted disturbance that affects the transmitted signal.
Types:
- Thermal noise.
- Atmospheric noise.
- Impulse noise.
- Electromagnetic interference.
- Crosstalk.
 Channel Distortion
Distortion occurs when a channel changes the amplitude, phase or timing characteristics of a transmitted signal.
Effects:
- Signal degradation.
- Inter-symbol interference.
- Reduced communication reliability.
 Channel Capacity
Channel capacity is the maximum theoretical rate at which information can be transmitted reliably through a communication channel under specified conditions.
It is measured in bits per second (bps).

 SHANNON-HARTLEY THEOREM
The Shannon-Hartley theorem determines the theoretical maximum information capacity of a band-limited communication channel affected by additive white Gaussian noise.
Formula:
    C = B log₂(1 + S/N)
Where:
C = channel capacity in bits per second.
B = channel bandwidth in Hz.
S = average signal power.
N = average noise power.
S/N must be a linear power ratio, not a value directly expressed in decibels.
 Importance;
The theorem establishes the relationship between:
- Channel bandwidth.
- Signal power.
- Noise power.
- Maximum information transmission rate.
  Increasing Channel Capacity;
Capacity can be increased by:
- Increasing bandwidth.
- Increasing signal-to-noise ratio.
- Reducing noise.
- Improving channel efficiency.
However, practical systems have limits imposed by available spectrum, power, hardware and regulations.
  Shannon Limit;
The Shannon limit represents a theoretical performance boundary for reliable communication over a specified channel model.
It does not mean every practical system can achieve this limit with finite complexity and latency.

 CHANNEL CODING AND ERROR CONTROL
Channel coding introduces structured redundancy into transmitted data to improve reliability in the presence of noise and interference.
Unlike source coding, which removes redundancy, channel coding deliberately adds redundancy.
  Error Detection;
Detects whether transmitted information has been corrupted.
Common methods:
 Parity Bit
An additional bit is added to make the number of ones even or odd.
Types:
- Even parity.
- Odd parity.
 Checksum
A value calculated from a data block and used to detect accidental corruption.
 Cyclic Redundancy Check (CRC)
A polynomial-based error-detection method commonly used in networks and storage systems.
  Error Correction;
Allows a receiver to identify and correct certain errors without retransmission.
Examples:
- Hamming codes.
- Reed-Solomon codes.
- Convolutional codes.
- Turbo codes.
- LDPC codes.
 Hamming Distance
Hamming distance is the number of bit positions in which two binary codewords differ.
Example:
101101
100001
Hamming distance = 2.
 Minimum Hamming Distance
The minimum Hamming distance of a code is the smallest distance between any two distinct valid codewords.
For minimum distance dmin:
Error detection capability:
    Detect up to dmin - 1 errors.
Error correction capability:
    Correct up to floor((dmin - 1)/2) errors.
 Hamming Code
A linear block code used for error detection and correction.
For a standard Hamming code with r parity bits:
    n = 2ʳ - 1
    k = 2ʳ - r - 1
Where:
n = total codeword bits.
k = data bits.
r = parity bits.
Example:
Hamming (7,4):
- 4 data bits.
- 3 parity bits.
- 7 total bits.
A standard Hamming (7,4) code has minimum distance 3 and can correct one bit error or detect up to two errors, but not both capabilities simultaneously without additional mechanisms.
 Forward Error Correction (FEC)
FEC adds redundancy to allow the receiver to correct errors without requesting retransmission.
Applications:
- Satellite communication.
- Deep-space communication.
- Digital broadcasting.
- Wireless communication.

 CHANNEL CODING THEOREM
  Shannon Channel Coding Theorem;
For a communication channel with capacity C, reliable communication is theoretically possible at rates below capacity.
    R < C
Where:
R = information transmission rate.
C = channel capacity.
If the transmission rate exceeds channel capacity:
    R > C
Arbitrarily reliable communication is not possible under the assumed channel model.
 Significance
The theorem demonstrates that:
- Noise does not make reliable communication impossible.
- Appropriate channel coding can significantly reduce error probability.
- Communication reliability depends on transmission rate and channel capacity.
 Coding Rate
Coding rate is the ratio of information bits to transmitted coded bits.
    Rcode = k/n
Where:
k = information bits.
n = total coded bits.
A lower coding rate generally introduces more redundancy and can provide stronger error protection, depending on the code and decoding method.

 DIFFERENTIAL ENTROPY
Differential entropy is an extension of entropy for continuous random variables.
For a continuous random variable with probability density function f(x):
    h(X) = -∫f(x)log₂f(x)dx
 Applications
- Continuous communication channels.
- Signal modelling.
- Gaussian noise analysis.
- Statistical signal processing.
 Important Distinction
Discrete entropy and differential entropy are not identical.
Differential entropy:
- Can be negative.
- Depends on the units and scaling of the variable.
- Is not directly equivalent to the number of bits needed to encode a continuous value.
Practical digital representation of continuous signals requires quantization or another finite representation.

 GAUSSIAN CHANNEL AND NOISE
  Gaussian Noise;
Gaussian noise is a random signal whose amplitude follows a Gaussian (normal) probability distribution.
Probability density function:   
    f(x) = (1/(σ√(2π)))e^(-(x-μ)²/(2σ²))
Where:
μ = mean.
σ = standard deviation.
 Additive White Gaussian Noise (AWGN)
A mathematical channel-noise model in which:
- Noise is added to the transmitted signal.
- Noise has a Gaussian amplitude distribution.
- Noise has a flat power spectral density over the modelled bandwidth.
Received signal:
    r(t) = s(t) + n(t)
Where:
r(t) = received signal.
s(t) = transmitted signal.
n(t) = noise.
  Signal-to-Noise Ratio;
SNR = S/N
In decibels:
    SNR(dB) = 10log₁₀(S/N)
 Applications
- Wireless communication analysis.
- Receiver design.
- Digital modulation performance.
- Error probability calculations.
- Communication-channel simulation.

 DATA COMPRESSION AND INFORMATION THEORY
Data compression reduces the number of bits required to represent information.
  Lossless Compression;
Original information is recovered exactly.
Examples:
- Huffman coding.
- Arithmetic coding.
- Lempel-Ziv algorithms.
- Run-Length Encoding.
  Lossy Compression;
Some information is discarded to achieve greater compression.
Examples:
- JPEG images.
- MP3 audio.
- AAC audio.
- Video compression.
  Compression Ratio;
Compression ratio:
    CR = Original data size / Compressed data size
Example:
If a file of 10 MB is compressed to 2 MB:
    CR = 10/2 = 5:1
  Compression Efficiency;
Compression efficiency depends on:
- Source entropy.
- Data redundancy.
- Coding method.
- Acceptable reconstruction quality.
- Computational complexity.
 Applications
- Image storage.
- Audio and video streaming.
- File compression.
- Database systems.
- Communication networks.

 MUTUAL INFORMATION AND CHANNEL PERFORMANCE
  Mutual Information;
Measures how much information the received signal provides about the transmitted signal.
    I(X;Y) = H(X) - H(X|Y)
  Channel Transition Probability;
A channel can be described using conditional probabilities:
    P(Y|X)
These probabilities describe the likelihood of receiving a particular output given a transmitted input.
  Binary Symmetric Channel (BSC);
A simple channel model in which each transmitted bit has probability p of being flipped.
If the input bit is 0:
- Output 0 with probability 1-p.
- Output 1 with probability p.
If the input bit is 1:
- Output 1 with probability 1-p.
- Output 0 with probability p.
Capacity:
    C = 1 - H₂(p)
Where:
    H₂(p) = -p log₂p - (1-p)log₂(1-p)
The capacity is measured in bits per channel use.
  Binary Erasure Channel (BEC);
A channel in which transmitted bits may be erased rather than changed.
The receiver knows which bits were erased.
For erasure probability ε:
    C = 1 - ε
Applications:
- Communication-channel modelling.
- Network coding.
- Error-control analysis.

 IMPORTANT STUDY AND ENGINEERING TIPS
1. Understand information as a measure of uncertainty rather than simply the amount of data.
2. Master self-information and Shannon entropy. Practise calculating entropy from probability distributions.
3. Remember that entropy is maximum when all possible outcomes are equally likely.
4. Understand the difference between entropy, joint entropy, conditional entropy and mutual information.
5. Distinguish source coding from channel coding:
   - Source coding removes redundancy.
   - Channel coding adds redundancy for error protection.
6. Learn Huffman coding step by step, including tree construction and average code-length calculations.
7. Understand the difference between lossless and lossy compression and know their practical applications.
8. Master the Shannon-Hartley theorem and practise calculating channel capacity from bandwidth and SNR.
9. Always convert SNR from decibels into a linear power ratio before substituting into the Shannon-Hartley equation.
10. Understand Hamming distance, minimum distance, error detection and error correction capabilities.
11. Learn how Shannon's source coding and channel coding theorems establish theoretical limits in communication systems.
12. Understand AWGN, binary symmetric channels and binary erasure channels.
13. Connect information theory to practical digital communication systems, especially modulation, coding and decoding.
14. Practise numerical problems involving entropy, coding efficiency, channel capacity, Hamming codes and probability distributions.
